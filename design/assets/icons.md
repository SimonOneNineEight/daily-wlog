# Icon manifest

79 glyphs vendored from [Lucide](https://lucide.dev) (MIT) at stroke weight 1.75 in the
Claude Design projects. Standing in for SF Symbols (not redistributable) — swap for the real
set or an exported subset in production. The SVGs themselves were not copied into this repo:
they are standard Lucide glyphs, reproducible by name from the `lucide` /
`lucide-react-native` packages.

image, list, list-filter, funnel, palette, pencil, plus, search, settings, trash-2, x,
camera. Everything else is category-picker vocabulary. `tag` is the default for a new
category. Emoji are banned as icons everywhere.
