# CategoryDot / CategoryDots
The calendar's only color. `CategoryDots` renders up to four in entry order and collapses the rest into "+n".

```jsx
<CategoryDots colors={["green", "clay", "blue", "orange", "violet"]} />
<CategoryDot color="pink" size="list" />
```

Colors are preset names (`clay amber olive fern sage lake denim plum rose cocoa`) or any CSS color for a custom category. Dots never blink or pulse.
