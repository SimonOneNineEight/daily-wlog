# ListRow
Row inside an inset white group — category management, settings.

```jsx
<ListRow first leading={<CategoryIcon icon="dumbbell" color="green" />} title="Sport" subtitle="3 subcategories" chevron onClick={open} />
```

Set `first`/`last` on the ends of a group so the corners round. Separators are drawn by the row itself; don't wrap rows in another card.
