# Button
Neutral text button for chrome; use it for Save, Cancel, and any bar action.

```jsx
<Button variant="primary" size="large" fullWidth>Save entry</Button>
<Button variant="ghost" icon="chevron-left">Back</Button>
```

Variants: `primary` (near-black fill), `secondary` (grey fill), `ghost`, `outline`, `destructive` (used only for delete of an unused category). No variant is tinted with a category color. Press state is opacity, not a hue shift.
