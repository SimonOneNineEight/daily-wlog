# MiniMonth
One of the twelve grids in the year view.

```jsx
<MiniMonth year={2026} month={7} today={17} firstColors={{ 3: "green", 12: "clay" }} />
```

`firstColors` is the day's FIRST entry's color only — one color per day, rendered as a solid rounded box with the numeral punched out in white. Never stripe two categories in one box.
